---
name: learn-map
description: Create or revise the high-level subject and prerequisite map for an agreed learning goal.
---

Read the `learn-session` skill’s `references/state.md` before reading or changing course records. Resolve that skill by its frontmatter name; installed folder names may differ. Reuse a contract already loaded in this session.

Read the confirmed learning brief and existing curriculum. Inspect credible textbook contents or university syllabi suited to the target level. Register inspected sources using the shared source rules.

Create only main nodes: stable ID, name, subject/foundation role, intended scope, essential dependencies, and helpful background links. Cover the target abilities and include only the prerequisite depth they require. Preserve parallel paths; list a valid suggested order rather than pretending every node requires the previous one.

Keep domain requirements separate from the learner’s existing knowledge. Write the map to `curriculum.yaml` as a draft with source references. On revision, preserve IDs and progress links, increment the revision, and invalidate affected approval/critique markers.

Completion means every target ability has a place, every dependency resolves, and essential dependencies are acyclic. Send the map to `learn-critique`; then address findings and present a compact diagram plus scope descriptions. Record the learner’s approval of this revision before expanding concepts.
